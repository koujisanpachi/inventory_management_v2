# 在庫管理アプリ Ver.1（ローカル保存版）

## 機能
- 電材・水部材・冷凍部材・その他の4カテゴリー
- 商品の登録・編集・削除
- カテゴリー別の商品一覧・検索
- 棚卸し前数量と実棚卸し数量の比較、差異表示
- 棚卸し確定時に在庫数を更新し、履歴を保存
- 全カテゴリー在庫一覧、検索、カテゴリー絞り込み
- CSV出力（1商品1行、Excel向けUTF-8 BOM付き）
- JSONバックアップ・復元
- iPhoneホーム画面追加に対応するPWA構成

## GitHub Pagesで公開する手順
1. GitHubにログインし、新しいリポジトリを作成する（例: `inventory-management`）。
2. このZIP内のファイルをすべてリポジトリの直下にアップロードする。
3. リポジトリの **Settings → Pages** を開く。
4. Build and deployment の Source を **Deploy from a branch** にする。
5. Branch を `main`、フォルダーを `/ (root)` にして Save。
6. 数分後に表示される公開URLをiPhoneのSafariで開く。

## iPhoneでホーム画面に追加
1. Safariで公開URLを開く。
2. 共有ボタンを押す。
3. **ホーム画面に追加**を選ぶ。
4. 追加したアイコンから起動する。

## データ保存について（重要）
- 商品・棚卸し履歴は、アプリを開いたブラウザ内のIndexedDBに保存されます。
- GitHub Pagesにアプリを公開しても、データがGitHubに送信されることはありません。
- 別の端末・別ブラウザとは自動共有されません。
- Safariのサイトデータ削除、端末故障、ブラウザのストレージ消去などでデータが失われる可能性があります。定期的に **データ管理 → バックアップを書き出す** を実行し、JSONファイルをiCloud DriveやGoogle Drive等に保存してください。
- CSVは在庫一覧を表計算ソフトで扱うための出力です。完全な復元にはJSONバックアップを使用してください。
- JSON復元は現在のデータを上書きします。復元前に現在のデータもバックアップしてください。

## 将来のクラウド共有に向けた設計
各商品にUUID形式の商品IDを付け、作成日時・更新日時を保存しています。棚卸し履歴も独立したレコードとして保存します。将来クラウドDBへ移行する際は、商品IDをキーにしてデータを移行する想定です。

## 初版の制約
- ログイン・ユーザー権限・複数端末同期はありません。
- 複数端末で同じデータを編集する用途にはまだ使用しないでください。
- 棚卸し確定処理は端末内で順次保存します。確定中にアプリを閉じないでください。
