# 在庫管理アプリ Firebase共有版

## 機能
- カテゴリー別の商品管理・検索
- 商品の登録・編集・削除
- 棚卸し・履歴管理
- カテゴリーの追加・編集・削除・表示順変更（↑↓）
- CSV出力、JSONバックアップ・復元
- Google認証＋利用者PIN
- Firebase Firestoreによる複数利用者・複数端末間のデータ共有
- iPhoneホーム画面追加に対応するPWA構成

## GitHub Pagesへの反映
1. ZIPを解凍する。
2. 中のファイルをすべてGitHubリポジトリ直下へアップロードする。
3. 既存ファイルを上書きしてCommit changes。
4. 数分待ってから公開URLを開く。

## データ保存について
- 商品・カテゴリー・棚卸し履歴はFirebase Cloud Firestoreに保存されます。
- 同じFirebaseプロジェクトにログインする利用者・端末間でデータを共有します。
- ブラウザのサイトデータ削除や端末故障で、Firestore上の在庫データそのものは消えません。
- 万一に備え、定期的に「データ管理 > バックアップを書き出す」でJSONを保存してください。
- CSVは一覧確認用です。完全な復元にはJSONバックアップを使用してください。

## 注意
Googleアカウントは共有アカウント、PINは利用者識別用の簡易PINです。PINはクライアント側のコードに含まれるため、強固な個人認証ではありません。Firestoreのセキュリティルールも、Google認証済みかどうかを基準にしています。
